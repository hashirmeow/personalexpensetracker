Place the locally licensed Lemon Milk font files here to enable the custom typeface:

- `LEMONMILK-Light.otf`
- `LEMONMILK-Regular.otf`
- `LEMONMILK-Medium.otf`
- `LEMONMILK-Bold.otf`

Font files are ignored by Git and are not redistributed with this project. Download them from the creator's DaFont page: https://www.dafont.com/lemon-milk.font
